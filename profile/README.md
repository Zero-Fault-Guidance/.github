# Zero Fault Guidance

Zero Fault Guidance (ZFG) builds software that helps defense contractors meet their cybersecurity and security compliance requirements with less effort, from CMMC and NIST SP 800-171 readiness to day-to-day security operations.

## Products

- **PocketCMMC**: CMMC readiness in your pocket. Available on the [App Store](https://apps.apple.com/in/app/pocketcmmc-cmmc-guide-tools/id6779566081) and [Google Play](https://play.google.com/store/apps/details?id=com.zerofaultguidance.pocketcmmc&hl=en-US).
